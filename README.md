### Projects

**KonsulExpert** *(private repository — client project)* — Online consultation marketplace, solo-built during a software engineering internship at PT Beone Optima Solusi. Covers the full flow: client search, consultant booking and scheduling, payment via Duitku, admin/consultant dashboards, consultant qualification and availability management, and automated tests across booking, refund, and admin-access paths. Deployed through a Dockerized pipeline with GitLab CI/CD.
`Next.js` `React` `PostgreSQL` `Tailwind CSS` `Docker` `GitLab CI/CD`

**[SIPEDA](https://sipeda.vercel.app/)** — Blood donation management system for **PMI Kabupaten Indramayu**, currently in active use. Rebuilt from v1 to v2 off a full PRD, delivered phase by phase.
`Next.js` `React` `Supabase` `Tailwind CSS`

**[Traffic Density Classifier](https://traffic-density-cnn.vercel.app)** — CNN built on MobileNetV2 transfer learning that classifies road traffic density from images, deployed and live.
`Python` `TensorFlow/Keras` `Vercel`

**Helmet Detection** *(Streamlit demo currently offline — free-tier hosting limit reached)* — Real-time helmet compliance detection using YOLOv8, identifying whether riders are wearing helmets from image/video input.
`Python` `YOLOv8` `Computer Vision`
